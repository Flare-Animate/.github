## Flare

# Project Overview: 
Flare is a fork of OpenToonz, tuned to recapture the intuitive feel and capabilities of Adobe Flash/Animate. We're building an accessible tool that is developed by the community.

# Why Now?: 
Adobe Animates's shutdown will severly damage the animation industry, an alternative that requires as little learning for animators transitioning from Adobe is needed.

# Features:
* Everything OpenToonz is already capable of.
* Full .FLA and .SWF file format support/conversion.
* A sleak, modern UI with a layout identical to Adobe Animate

# Development/Contributing:

Flare is and will always be 100% Open Source and free to use for everyone, anyone can make a PR or start a discussion asking for a certain feature, people will also be able to apply for Write Access to become official developers for Flare.
